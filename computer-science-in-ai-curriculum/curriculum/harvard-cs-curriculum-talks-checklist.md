# Harvard SEAS Computer Science Curriculum — 50-Minute Talk Checklist

Source: [Harvard SEAS Computer Science Course Listing](https://seas.harvard.edu/computer-science/courses)

**A note on this one:** unlike Amherst/BGSU/Purdue/MIT, Harvard's course page doesn't link out to detailed per-course syllabi — the catalog description *is* the syllabus-equivalent content, and each "COURSE WEBSITE" link on the page just points to Harvard's term-specific class locator/registrar tool, not a stable course site worth linking here. So this checklist is built directly from the catalog blurbs on the source page above, the same way the Amherst checklist was. Several courses (91R Supervised Reading and Research, 2901/2902 the PhD professional-development seminar, 2990R Special Topics/independent study) have no fixed content and are excluded — there's nothing to build a talk from. Courses offered at both undergraduate and graduate level under different numbers (e.g. 1411/2411, 1440R/2440R) are listed separately since Harvard treats them as distinct listings, even where the catalog description is identical.
