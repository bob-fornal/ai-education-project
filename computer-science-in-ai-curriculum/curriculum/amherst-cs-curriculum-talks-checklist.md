# Amherst CS Curriculum — 50-Minute Talk Checklist

Source: [Amherst CS Curriculum](https://www.amherst.edu/academiclife/departments/computer_science/courses?display=curriculum)

Each item below is scoped to be presentable as a single, self-contained 50-minute talk, derived from topics explicitly named in that course's description. Courses with narrow scope yield fewer talks; broad survey courses (Algorithms, ML, NLP, Systems) yield more.
